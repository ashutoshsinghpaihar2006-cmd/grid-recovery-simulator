🎯 Problem Statement & Real-World Motivation

Mitigating Cascading Outages and Protecting Critical Life-Safety Infrastructure
SLIDE 02 / 12

⚠️ The Engineering Problem

High-voltage regional power grids operate as tight, heavily loaded meshes. When a transmission line trips (e.g. from severe storm damage or transformer explosions), the electrical current is automatically shunted onto parallel lines.

Cascading Blackout Risk
Overcurrent trips adjacent lines in seconds, leading to widespread regional blackout (e.g. 2012 Northern Grid Collapse).

Finding optimal, least-impedance bypass paths manually across hundreds of substations is NP-hard in real-time operations.

📐 Formal Mathematical Definition

Given an electrical network represented as a weighted graph G = (V, E):

  • Vertices (V): Power plants ($V_{gen}$), substations ($V_{sub}$), and facilities ($V_{crit}$).
  • Edges (E): Transmission cables with weights $w(e) > 0$ representing line impedance in $\Omega\text{-km}$.
  • Priorities: $P(v) \in \{0, 1, 2, 3, 4\}$ where Tier 1 = Hospitals / Trauma Centers.
  • Fault Set: $F \subseteq (V \cup E)$ representing failed components.

Objective: Partition reachable vs islanded nodes, discover single-line bridges in linear time, and compute alternate paths minimizing impedance while restoring Tier 1 facilities first.

🧩 Algorithmic Paradigm & Core Approach

Combining Linear Graph Traversal, Greedy Shortest Paths & Priority Queuing
SLIDE 03 / 12

1. Traversal & Connectivity

Algorithms: BFS & Tarjan's DFS

Paradigm: Graph Traversal $\mathcal{O}(V + E)$.

• BFS: Determines reachability from active generation sources and calculates minimum transmission hop distance.
• Tarjan's DFS: Discovers cut-edges (bridges) in a single pass using discovery and low-link numbers.

2. Shortest Bypass Routing

Algorithm: Dijkstra’s Algorithm

Paradigm: Greedy Method $\mathcal{O}((V + E) \log V)$.

Finds the least-impedance, least-loss path around broken transmission lines using a binary Min-Heap. Guarantees non-negative edge weights $w(e) > 0$.

3. Spanning Trees & PQ

Algorithms: Kruskal, Prim, Min-Heap PQ

Paradigm: Greedy Optimization + Priority Dispatch.

• Kruskal / Prim: Builds minimal transmission backbone without cycles.
• Priority Queue: Enforces life-safety ordering (Hospitals restored before residential/industrial).

Why this approach over Brute-Force?

A naive exhaustive path enumeration between generator and destination examines $\mathcal{O}(V!)$ or $\mathcal{O}(2^V)$ paths—exponentially blowing up even for 15 nodes. Formulating bypass recovery as Dijkstra edge relaxation and Kruskal cycle-free spanning guarantees sub-millisecond execution times ($< 50\text{ }\mu s$) on standard hardware.

🔄 Algorithm Logic & Step-by-Step Dry Run

Trace of Priority Recovery & Dijkstra Edge Relaxation during Line Failure
SLIDE 05 / 12

Algorithm Logic Flow

Algorithm PriorityRecovery(G, Generators, BlackoutNodes):
  PQ = MinHeap(comparator: Tier ASC, Demand DESC)
  for node in BlackoutNodes:
    PQ.push(node)

  while !PQ.empty():
    target = PQ.pop() // Hospital Tier 1 emerges first
    best_dist = INF, best_path = []

    for gen in Generators:
      (dist, path) = Dijkstra(G, gen, target)
      if dist < best_dist:
        best_dist = dist, best_path = path

    if best_path != NULL:
      Energize(target)
      HighlightBypassPath(best_path)

⏱️ Theoretical Complexity Analysis

Mathematical Proofs for Time and Space Complexities (Big-O Notation)
SLIDE 06 / 12

Time Complexity Derivations

1. BFS & Tarjan’s DFS: $\mathcal{O}(V + E)$
Every vertex is visited once ($\mathcal{O}(V)$) and each incident edge is traversed exactly once ($\mathcal{O}(E)$). In Tarjan's, ancestor back-edge updates take $\mathcal{O}(1)$ inside the loop. Total time is strictly linear $\mathcal{O}(V + E)$.

2. Dijkstra's Algorithm: $\mathcal{O}((V + E) \log V)$
With a binary min-heap: $$\sum_{v \in V} \text{Extract-Min}(V) + \sum_{e \in E} \text{Decrease-Key}(e) = V \log V + E \log V$$ $$\implies \mathcal{O}((V + E) \log V)$$

3. Kruskal’s Algorithm: $\mathcal{O}(E \log E)$
Sorting $E$ edges takes $\mathcal{O}(E \log E)$. With DSU (rank + path compression), $2E$ finds and $V-1$ unions take $\mathcal{O}(E \cdot \alpha(V))$. Sorting dominates $\implies \mathcal{O}(E \log E)$.

Space Complexity & Memory Bounds

Auxiliary Space Breakdown:
• Adjacency List: $\mathcal{O}(V + E)$ entries
• Distance & Parent Arrays: $2 \times \mathcal{O}(V)$
• Min-Heap Elements: At most $\mathcal{O}(V)$ nodes
• DSU Parent & Rank Arrays: $2 \times \mathcal{O}(V)$
• Recursion Call Stack (DFS): Maximum depth $\mathcal{O}(V)$

Total Space: $\mathcal{O}(V + E)$
Strictly linear auxiliary memory. For a city grid of 1,000 substations and 2,500 lines, memory consumption is under 5 MB.

⚖️ Comparative Analysis of Algorithmic Approaches

Trade-Offs between Single-Source Shortest Paths and Spanning Trees
SLIDE 09 / 12
Evaluation Parameter Dijkstra's Shortest Path Kruskal's Algorithm (MST) Prim's Algorithm (MST)
Optimization Target Minimizes latency/impedance from one source to a destination. Minimizes total sum of edge weights across all nodes in the grid. Minimizes total edge weights rooted from an active generator.
Practical Role Bypassing an isolated tripped transmission line. Complete grid reconstruction after full black-system collapse. Progressive black-start energization outward from plant.
Time Complexity $\mathcal{O}((V + E) \log V)$ $\mathcal{O}(E \log E)$ $\mathcal{O}(E \log V)$
Core Data Structure Min-Heap Priority Queue Disjoint Set Union (DSU) + Quicksort Min-Heap + Visited Boolean Array
Algorithmic Trade-off Optimal for single-target bypass; does not minimize total copper/wire usage. Guarantees global minimal wire usage; individual paths may not be shortest. Ideal when generator root is fixed; requires frontier edge heap maintenance.

🧪 Edge Cases, Boundary Testing & Verification

Ensuring Robustness under Extreme Topological Disruptions
SLIDE 10 / 12

Boundary & Stress Scenarios Tested

  • Complete Physical Isolation (Node Cut): When all 4 incident lines to AIIMS Hospital are cut, Dijkstra terminates with distance $\infty$. The Priority Queue logs the failure without crashing and proceeds to lower tiers.
  • Total Generation Collapse: If all 3 power stations trip simultaneously, the system aborts bypass calculation and triggers a red SCADA critical alert.
  • Zero / Negative Impedance Prevention: Line impedances are strictly bounded ($w(e) > 0$), preventing negative cycle loops.
  • Cycle Rejection in MST: Tested on high-density meshes; DSU verified to reject redundant chords, spanning exactly $|V| - 1$ edges.

Verification Methodology

1. Hand Calculations & Trace Validation:
Step-by-step paper-pencil Dijkstra and Kruskal traces were executed on a 4-node and 6-node subgrid; algorithm outputs matched manual results 100%.

2. Automated Unit Tests:
A test suite verified Min-Heap ordering invariants, DSU path compression, and graph reachability invariants across 50 simulated random failure cycles.

🚀 Challenges, Limitations & Future Scope

Engineering Hurdles Overcome and Smart-Grid Expansion Roadmap
SLIDE 11 / 12

Challenges & Solutions

1. Spiderweb Map Clutter:
Problem: Straight line chords crisscrossing central Delhi created a cluttered visual mess.
Solution: Implemented quadratic Bézier interpolation (generateCurvedPath) with alternating curvature ($\pm 0.08$) and clear geographic hub spacing.

2. Priority Inversion:
Problem: High-demand residential loads could starve low-demand hospitals.
Solution: Formulated a strict two-tier Min-Heap comparator ordering by $(\text{Priority Tier}, -\text{Demand})$.

Limitations & Future Scope

Current Limitations:
The simulator models graph-theoretic impedance and connectivity, but does not solve non-linear AC power-flow differential equations (reactive VARs, voltage phase angles).

Future Upgrades:
• Machine Learning: LSTM / GNN models for predictive failure forecasting before physical line cuts occur.
• Renewable Injection: Dynamic battery storage and rooftop solar load balancing.
